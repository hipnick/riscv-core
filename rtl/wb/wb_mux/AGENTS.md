# Write-Back Multiplexer (WB_MUX) Documentation

## Overview
The WB_MUX is the final stage of the datapath. It acts as a data-selector that determines which functional unit provides the data to be stored in the Register File destination register (`rd`).

## Ports
| Name             | Direction | Type     | Description                                                              |
|:-----------------|:----------|:---------|:-------------------------------------------------------------------------|
| **alu_result_i** | Input     | data_t   | Computational result from the ALU.                                       |
| **lsu_data_i**   | Input     | data_t   | Loaded data from the Load-Store Unit.                                    |
| **pc_plus_4_i**  | Input     | data_t   | The return address (Current PC + 4) for jump-and-link instructions.       |
| **wb_sel_i**     | Input     | wb_sel_e | Control signal determining the source (WB_ALU, WB_MEM, or WB_PC4).       |
| **wb_data_o**    | Output    | data_t   | The final data to be written into the Register File.                     |

## Selection Logic
The `wb_sel_i` signal is generated by the Main Decoder based on the opcode of the instruction currently in the Write-Back stage.

| Selection | Path Description | Instruction Context |
| :--- | :--- | :--- |
| **WB_ALU** | Routes the output of the ALU directly to the Register File. | Used for all computational instructions (e.g., `ADD`, `XOR`, `SLTI`). |
| **WB_MEM** | Routes data retrieved from Data Memory (via the LSU) to the Register File. | Used exclusively for `LOAD` instructions. |
| **WB_PC4** | Routes the incremented Program Counter ($PC + 4$) to the Register File. | Used for `JAL` and `JALR` to save the return address (linking). |
