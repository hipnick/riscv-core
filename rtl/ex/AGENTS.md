# Execute (EX) Stage Specification

The **Execute (EX) Stage** is the functional core of the RISC-V pipeline. It receives decoded operands and control signals from the ID stage to perform arithmetic, logical, shift, branch comparison, and target address generation operations.

## 1. Architecture Overview
The EX stage consists of three primary combinational subunits:
1.  **Arithmetic Logic Unit (ALU):** Responsible for computational instructions and data address generation.
2.  **Branch Comparator (BC):** Dedicated logic for evaluating branch conditions to determine control flow changes.
3.  **Address Generation Unit (AGU):** Specialized adder for calculating branch and jump target addresses in parallel with the ALU.
4.  **Forwarding Unit (FWD):** Logic that detects if the current source operands are being updated by instructions currently in the MEM or WB stages and selects the most recent data.

## 2. Interface Definition

### Input Signals
| Signal | Type | Source | Description |
| :--- | :--- | :--- | :--- |
| `alu_ctrl_i` | alu_ctrl_e | ID Stage | Operation selector for the ALU (from `riscv_types_pkg`). |
| `bc_ctrl_i` | bc_ctrl_e | ID Stage | Comparison selector for the BC (from `riscv_types_pkg`). |
| `op_a_i` | data_t | ID/Forward | Primary source operand (`rs1` or `pc_i`). |
| `op_b_i` | data_t | ID/Forward | Secondary source operand (`rs2` or `imm`). |
| `op_a_addr_i`| address_t | ID Stage | Register address for rs1 (Metadata for Forwarding). |
| `op_b_addr_i`| address_t | ID Stage | Register address for rs2 (Metadata for Forwarding). |
| `pc_i` | data_t | ID Stage | Program Counter of the current instruction. |
| `imm_i` | data_t | ID Stage | Sign-extended imm_i value. |
| `jalr_sel_i` | logic | ID Stage | Control signal; High if instruction is `JALR`. |
| **Forwarding Inputs** | | | |
| `rd_addr_mem_i` | address_t | MEM Stage | Destination register of instruction currently in MEM. |
| `rd_addr_wb_i` | address_t | WB Stage | Destination register of instruction currently in WB. |
| `reg_we_mem_i` | logic | MEM Stage | Write-enable bit for instruction in MEM stage. |
| `reg_we_wb_i` | logic | WB Stage | Write-enable bit for instruction in WB stage. |
| `alu_result_mem_i`| data_t | MEM Stage | Data result calculated in the previous cycle. |
| `wb_data_i` | data_t | WB Stage | Final data result from the WB stage. |

### Internal Control Signals (Forwarding Unit Outputs)
These signals are generated by the `fwd` module and consumed by the operand muxes within the EX stage.
| Signal | Type | Description |
| :--- | :--- | :--- |
| `fwd_a_sel` | `fwd_ctrl_e` | Selects between `op_a_i`, `alu_result_mem_i`, or `wb_data_i`. |
| `fwd_b_sel` | `fwd_ctrl_e` | Selects between `op_b_i`, `alu_result_mem_i`, or `wb_data_i`. |

### Output Signals
| Signal | Type | Destination | Description |
| :--- | :--- | :--- | :--- |
| `alu_result_o` | data_t | MEM/WB | Data result or calculated memory address. |
| `target_addr_o` | data_t | IF Stage | Calculated jump/branch destination address. |
| `bc_taken_o` | logic | Control Unit | High if branch condition is met. |
| `alu_zero_o` | logic | Status | High if `alu_result_o` is all zeros. |
| `alu_negative_o` | logic | Status | High if `alu_result_o[31]` is 1 |
| `alu_overflow_o` | logic | Status | High if signed arithmetic alu_overflow_o occurs. |
